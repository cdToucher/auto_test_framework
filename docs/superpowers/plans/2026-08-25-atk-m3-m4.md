# atk M3/M4 实施计划：固化流水线、门禁、CI 集成与配套功能

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 完成框架闭环：`validate` 场景校验 → fixtures/重试增强执行 → `export` 固化编译（API 全确定性，UI 留 agent 填充）→ `doctor` 失败分类（自修复入口）→ JUnit XML 进 CI → `gate` 合并门禁；附 CI 定时样例、`init` 脚手架与角色规范文档。

**Architecture:** 沿用 M2 决策——atk 只做确定性环节。固化产物 = 自包含 pytest 文件（仅依赖 httpx），UI 步骤生成带指令注释的 NotImplementedError 占位，由 Agent 填充后 `doctor` 分类失败。门禁以运行记录与当前变更的一致性为核心判定。

**Tech Stack:** 既有栈；生成物运行仅需 httpx+pytest。

```python
from collections import Counter


@app.command()
def validate(
    root: Path = typer.Option("scenarios"),
):
    """校验场景库合法性（QA 提交前自查）。退出码 0/1。"""
    scs, errors = load_scenarios(root)
    for e in errors:
        typer.secho(f"[错误] {e}", fg=typer.colors.RED)
    dup = {n for n, c in Counter(s.scenario for s in scs).items() if c > 1}
    for n in sorted(dup):
        files = [s.file for s in scs if s.scenario == n]
        typer.secho(f"[警告] 场景名重复: {n} -> {', '.join(files)}", fg=typer.colors.YELLOW)
    ok = len([s for s in scs if s.scenario not in dup])
    typer.echo(f"{len(errors)} 个文件错误，{len(dup)} 个重名，{ok} 个场景通过校验")
    raise typer.Exit(code=1 if errors else 0)
```

```python
"""JUnit XML 输出：CI 平台通用测试报告格式。"""
import xml.etree.ElementTree as ET
from pathlib import Path


def write_junit(report, out_path: Path | str) -> Path:
    out_path = Path(out_path)
    out_path.parent.mkdir(parents=True, exist_ok=True)
    suites = ET.Element("testsuites")
    suite = ET.SubElement(suites, "testsuite", {
        "name": f"atk-{report.env_name}",
        "tests": str(report.total),
        "failures": str(report.failed_count),
        "errors": "0",
        "skipped": str(report.blocked_count),
    })
    for r in report.results:
        tc = ET.SubElement(suite, "testcase", {
            "classname": r.scenario.module, "name": r.scenario.scenario,
            "time": f"{r.duration_ms / 1000:.3f}",
        })
        if r.passed:
            continue
        detail = r.steps[-1].detail if r.steps else r.error_class
        if r.error_class in ("environment", "ui_unsupported", "empty"):
            ET.SubElement(tc, "skipped", {"message": f"[{r.error_class}] {detail}"})
        else:
            f = ET.SubElement(tc, "failure", {
                "message": f"[{r.error_class}] {detail}"[:300],
                "type": r.error_class,
            })
            f.text = "\n".join(f"{s.title}: {s.detail}" for s in r.steps)
    ET.ElementTree(suites).write(out_path, encoding="utf-8", xml_declaration=True)
    return out_path
```

### Task 7: `atk gate` 门禁校验

**Files:** Modify cli.py；Test `tests/test_gate.py`

- 判定规则（顺序）：
  1. run 记录不存在 → exit 2
  2. `rec.head_ref != --head(默认HEAD)` 或当前 `changed_files(base,head)` ≠ `rec.affected_files` → exit 1 “变更已漂移，请重新 plan”
  3. scenarios 有 assertion/config 失败 → exit 1
  4. intents 有 fail 或 suspect → exit 1（需人工定性后再 gate）
  5. 其余（含 blocked 记 warn）→ exit 0
